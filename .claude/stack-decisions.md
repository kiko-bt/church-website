---

# WHY NEXT.JS

Chosen because:

- App Router
- SSG support
- Vercel integration
- modern React architecture
- server components

---

# WHY SANITY

Chosen because:

- preacher-friendly CMS
- media uploads
- simple editing experience
- low maintenance

---

# WHY LOCAL JSON FOR BIBLE

Chosen because:

- deterministic rendering
- predictable search
- static generation
- no CMS instability
- no runtime Bible APIs

---

# WHY FUSE.JS

Chosen because:

- client-side search
- lightweight
- deterministic
- simple architecture

---

# WHY SSG

Chosen because:

- fast performance
- SEO
- lower hosting complexity
- lower runtime cost

---

# FINAL RULE

No stack changes without approval.
